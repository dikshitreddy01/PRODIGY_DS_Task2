# Prodigy InfoTech Data Science Internship — Task 02

## Task
Perform data cleaning and exploratory data analysis (EDA) on a dataset of choice and identify relationships, patterns, and trends.

## Dataset
Titanic passenger dataset.

Dataset source used by the notebook:
https://raw.githubusercontent.com/mwaskom/seaborn-data/master/titanic.csv

## What this project does
- Loads and inspects the Titanic dataset.
- Checks missing values and data types.
- Cleans missing `age`, `embarked`, and `embark_town` values.
- Removes the `deck` column because of extensive missing data.
- Analyzes survival by gender.
- Analyzes survival by passenger class.
- Visualizes age distribution.
- Compares average fare by survival outcome.

## Tools
- Python
- Pandas
- Matplotlib
- Jupyter Notebook / VS Code

## How to Run
1. Open `PRODIGY_DS_02.ipynb` in VS Code.
2. Select a Python/Jupyter kernel.
3. Install dependencies if needed:
   `python -m pip install pandas matplotlib jupyter`
4. Run the notebook cells from top to bottom.

## Conclusion
The EDA identifies clear relationships between survival and passenger characteristics, especially gender and passenger class. The project demonstrates practical data cleaning, exploration, aggregation, and visualization.
